# Harbor visual assets

Every v1.0 visual asset in this directory was drawn by hand specifically for The Harbor. The vectors use only original paths and basic SVG shapes; they do not trace or incorporate third-party artwork, fonts, raster images, scripts, or external resources.

### `assets/logos/harbor-mark.svg`

- Origin: Original Harbor artwork created for this repository.
- Purpose: Primary Harbor identity mark, designed to remain recognizable at 24 CSS pixels and in a single color.
- Decorative: no

### `assets/parchment/fibers.svg`

- Origin: Original Harbor artwork created for this repository.
- Purpose: Low-contrast repeating fibers for opt-in parchment surfaces and restrained application-frame texture.
- Decorative: yes

### `assets/icons/compass-rose.svg`

- Origin: Original Harbor artwork created for this repository.
- Purpose: Optional nautical ornament that must never carry meaning by itself.
- Decorative: yes
